# el-ultimo-combo
Juego de pelea 2D de Grupo RUNAS AI. Demo jugable en HTML5 con modo Versus y modo Story.

## Jugar online
Todo el juego está en `index.html` (un solo archivo, sin descargas ni instalación).
Con GitHub Pages activado (Settings → Pages → Deploy from branch → `main` / root) queda en:
https://lordty2024.github.io/el-ultimo-combo/
